## 🧭 Sobre o Projeto

Este projeto é uma **aplicação web para gerenciamento de detalhes de viagem**, desenvolvido durante o evento **Next Level Week (NLW)** promovido pela **Rocketseat**.

Implementei funcionalidades essenciais e melhorias no componente `TripDetails`, incluindo ajustes de responsividade e experiência do usuário. A aplicação tem como principal objetivo **organizar e centralizar links importantes relacionados a uma viagem**, facilitando o planejamento e o acesso rápido às informações durante todas as etapas da jornada.  

---

## ✨ Funcionalidades Principais

### ➕ Adicionar Links Importantes  
Usuários podem cadastrar novos links com título e URL para cada viagem.

### 📋 Exibir Links  
Visualização de uma lista de links cadastrados, com fácil acesso.

### 📱 Interface Responsiva  
A interface foi construída com **Tailwind CSS**, garantindo boa usabilidade em diferentes tamanhos de tela.

### ⚛️ Gerenciamento de Estado  
Utilização de **React Hooks** como `useState`, `useEffect` e `useCallback` para controle eficiente do estado da aplicação.

### 🌐 Requisições HTTP  
Utilização do **axios** para comunicação com o backend, permitindo a criação e busca de dados.

### 🎨 Ícones Intuitivos  
Uso da biblioteca **Lucide React** para incorporar ícones modernos e acessíveis na interface.

---

## 🚀 Tecnologias Utilizadas

- ✔️ **React** – Biblioteca JavaScript para interfaces modernas
- ✔️ **TypeScript** – Tipagem estática para maior segurança
- ✔️ **Tailwind CSS** – Estilização utilitária e responsiva
- ✔️ **Axios** – Requisições HTTP com facilidade
- ✔️ **Lucide React** – Conjunto de ícones para React
- ✔️ **Vite** – Build rápido para front-end
- ✔️ **SQLite** – Banco de dados leve e eficiente
- ✔️ **Prisma** – ORM moderno para manipulação do banco de dados

## ▶️ Passo a Passo  

### 🛠 **Executando a API**  

1️⃣ **Clone o repositório**:  
```bash
git clone https://github.com/diegoramosds/projeto-viagens.git

```

2️⃣ **Acesse o diretório da API** no terminal.
```bash
cd api-viagens
cd api
```

3️⃣ Execute para instalar as dependências do projeto.
```bash
npm install
```

4️⃣ Execute para iniciar o servidor da API.
```bash
npm run dev
```

5️⃣ Aguarde até que a API esteja rodando e ouvindo requisições na porta especificada.

<br>

### 💻 **Executando a Aplicação React** 

1️⃣ Acesse o diretório da aplicação React no terminal.
```bash
cd viagens
```

2️⃣ Execute  para instalar as dependências do projeto.
